# 2025-05-12 更新日志

## 功能优化

### 添加卖出页面样式统一

#### 需求背景
将已出售订单的"添加卖出"页面样式统一成手办管理的"添加手办"页面样式风格，提升系统整体视觉一致性。

#### 解决方案
**前端实现：**
- 将 `SoldOrderForm.vue` 从 `el-dialog` 组件改为全屏遮罩层 + 容器布局
- 采用左侧标签页布局（Komga风格），包含6个标签页：基础信息、买家信息、价格成本、物流信息、盈亏预览、订单备注
- 统一按钮样式（取消/保存）与手办管理模块一致
- 应用相同的标签页样式，包括激活状态左侧蓝色指示器、hover效果等
- 使用Font Awesome图标增强视觉效果
- 保持响应式设计，适配移动端显示

**样式特点：**
- 全屏半透明遮罩层背景
- 卡片式表单容器，圆角边框和阴影效果
- 左侧导航标签页，带图标和蓝色激活指示器
- 底部操作按钮区域，灰色背景分隔线

### 部署更新

- 执行 `docker-compose up -d --build` 重新部署服务
