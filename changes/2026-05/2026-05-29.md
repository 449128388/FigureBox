# 2026-05-29 更新日志

## 新增订单展示编号功能

### 需求描述
在尾款管理和手办导入功能中，为订单自动生成展示编号并存储到数据库中。

### 解决方案
在 `Order` 模型中添加 `display_order_number` 字段，创建 `OrderNumberService` 服务类生成编号，在尾款管理和手办导入时自动生成展示编号。

### 结果
- 新创建的订单自动分配展示编号
- 展示编号持久化存储在数据库中
- 买入订单详情优先使用数据库中的展示编号
- 兼容历史数据（无展示编号的订单动态生成）

## 修复买入订单详情500错误

### 问题描述
调用 `/api/trade_records/buy-order/2` 接口返回 500 Internal Server Error 错误。

### 解决方案
1. 修改 `buy_order_service.py` 中的 `_get_payment_details` 方法，将 `tx.transaction_no` 改为使用 `f"TRX-{tx.id}"` 生成交易流水号
2. 修改 `_get_logistics_info` 方法，将 `@staticmethod` 改为 `@classmethod`，修复 `cls` 未定义的错误

### 结果
- 买入订单详情接口可正常返回数据
- 支付明细中的交易流水号使用 `TRX-{id}` 格式

## 重构资产看板收益曲线

### 需求描述
资产看板-收益曲线(近1月)需要重构，计算方式变更为每日收益 = 当日总市值 − 当日总成本，并增加零轴参考线和红绿颜色区分。

### 解决方案
1. 创建 `ProfitCurveService` 服务类，实现每日收益计算逻辑
2. 修改 `dashboard_asset.py`，使用新的收益曲线服务替代原有的市值数据
3. 修改 `ChartSection.vue`，实现零轴参考线（灰色虚线）和红绿颜色区分
4. 处理边界情况：全新用户/空仓显示 y=0 直线

### 结果
- 收益曲线计算方式：每日收益 = 当日总市值 - 当日总成本
- 零轴参考线：灰色虚线 `#999`
- 颜色规则：曲线上方红色 `#FF4D4F`（盈利），下方绿色 `#52C41A`（亏损）
- 区域填充：盈利区域浅红色 `#FFE6E6`，亏损区域浅绿色 `#E6F7E6`
- 边界处理：全新用户/空仓显示 y=0 直线
