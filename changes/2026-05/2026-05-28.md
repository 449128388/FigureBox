## 修复订单类型判断逻辑

### 需求描述
修正买入订单详情中的订单类型判断逻辑。

### 解决方案
修改 `buy_order_service.py` 中的 `_get_order_type` 方法：
- 尾款 > 0：订单类型 = "预定"
- 状态 == "已取消"：订单类型 = "已取消预定"
- 尾款 == 0 且 未取消：
  - 备注包含"补仓" 或 平台 == "补仓"：订单类型 = "补仓"
  - 出荷日期存在且不为空：订单类型 = "全款预定"
  - 其他：订单类型 = "现货"

### 结果
- 订单类型判断符合业务逻辑
- 买入订单详情显示正确的订单类型
