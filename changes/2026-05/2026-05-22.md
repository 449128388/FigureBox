# 2026-05-22 更新日志

## 修复持仓列表快速卖出平台显示问题

### 问题描述
在持仓列表（按盈亏排序）中使用快速卖出功能后，已出售订单的"卖出平台"显示为"其他"，而不是"快速卖出"。

### 解决方案
在前端的卖出平台选项列表中添加"快速卖出"选项。

### 实现逻辑
- 修改 `BasicInfoTab.vue`：在卖出平台下拉选项中添加"快速卖出"
- 修改 `SoldOrdersSearch.vue`：在卖出平台筛选选项中添加"快速卖出"

### 修复后效果
- 通过快速卖出功能创建的订单，卖出平台正确显示为"快速卖出"
- 已出售订单列表中可以按"快速卖出"筛选相关订单
