# 2026-06-15 更新日志

## 1. 修复收藏家模式藏品总数统计错误

### 问题背景
收藏家模式中顶部概览 + 三指标卡片的"藏品总数"统计错误，原逻辑通过统计有有效订单的手办种类数量来计算，未考虑实际持仓数量和部分卖出的情况。

### 解决方案
改为从 `asset_transactions` 表中统计各个手办的遗留总数，即所有买入交易的 `remaining_quantity` 字段总和。

### 实现逻辑
- **原逻辑**：`total_collection = len(figures)`，只统计手办种类数
- **新逻辑**：
  1. 查询所有有效的买入交易记录（`transaction_type='buy'` 且 `is_active=True`）
  2. 累加所有买入交易的 `remaining_quantity` 字段，得到实际持仓总数
  3. 获取有持仓的手办ID列表，查询这些手办的作品和厂商信息
  4. 统计覆盖的作品数和厂商数

### 结果
- 藏品总数现在准确反映用户实际持有的手办数量（考虑部分卖出的情况）
- 覆盖作品数和厂商数仅统计有实际持仓的手办
