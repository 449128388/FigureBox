# 2026-06-05 更新日志

## 1. 资产看板收益曲线本日收益动态获取

### 需求描述
修复资产看板-收益曲线(近1月)中无法看到系统时间本日收益的缺陷，系统时间本日收益为动态获取，不需要对过往没有数据的日期进行补全

### 解决方案
修改 `ProfitCurveService.get_profit_curve_data` 方法，使今日收益始终动态计算并添加到结果中

### 实现逻辑
- 修改查询条件，从持仓快照表中获取数据时排除今日（`snapshot_date < end_date`）
- 添加历史快照数据到结果列表
- 无论是否有历史数据，都动态计算今日收益并添加到结果末尾
- 使用 `calculate_daily_profit` 方法基于当前持仓计算今日浮动盈亏
- 移除对 `AssetValueCache` 表的查询逻辑，简化代码

### 结果
- 收益曲线始终显示本日收益（动态计算）
- 历史数据从持仓快照表获取
- 不需要对过往没有数据的日期进行补全

## 2. 删除买入完成订单新增页面的"单价"字段

### 需求描述
修复资产看板-交易-快速操作中的买入完成订单-新增买入订单页面的缺陷，字段"单价"为多余选项，需要删除"单价"前后端相关的代码

### 解决方案
删除前端 `CreateBuyOrderDrawer.vue` 和后端 `BuyOrderService.create_buy_order` 中的"单价"字段相关代码

### 实现逻辑
**前端修改：**
- 删除模板中的"单价"表单项
- 从 `formData` 中删除 `unitPrice` 字段
- 从 `formRules` 中删除 `unitPrice` 验证规则
- 从请求 payload 中删除 `unit_price` 字段
- 修改补仓备注生成逻辑，使用 `totalAmount` 替代 `unitPrice`
- 修改 watch 监听，监听 `totalAmount` 替代 `unitPrice`
- 修改 `resetForm` 方法，删除 `unitPrice` 重置

**后端修改：**
- 从 `create_buy_order` 方法的文档注释中删除 `unit_price` 参数说明
- 从订单数据提取逻辑中删除 `unit_price` 字段
- 删除单价验证逻辑（`unit_price <= 0`）
- 保留数量验证逻辑

### 结果
- 买入完成订单新增页面不再显示"单价"字段
- 订单创建逻辑不再依赖单价字段
- 补仓备注使用实付金额生成
