### 4. 解耦「海报展示数据」与「数据展示」—— 两套配置独立职责

**解决方案：** 原有代码中「海报展示数据」（poster_level）与「数据展示」（show_total/show_figures 等）存在交叉控制：
- 后端 `/share/profile` 返回的 `show_figures`/`show_asset`/`show_feed`/`show_tags` 被 AND 门控了 `poster_level == "full"`
- 前端 `ShareProfile.vue` 主页展示依赖 `summary_only`/`names_only`（来自 poster_level）来决定渲染模式
- 前端 `SharePoster.vue` 海报渲染中 `showAmount` 依赖了 `show_asset`（数据展示开关）

按需求将两套配置彻底解耦。

**实现逻辑：**
- **后端** `share.py`：
  - `get_shared_profile`：移除 `poster_level` 变量和 AND 门控，所有 `show_*` 字段直接返回原始隐私设置值
  - `get_shared_cabinets`：移除 `poster_level` 门控，`show_figures` 直接取原始值
  - `get_shared_activities`：移除 `poster_level == "full"` 判断，直接由 `show_feed` 控制
- **前端** `ShareProfile.vue`：
  - 移除 `summary_only`/`names_only` 条件渲染分支
  - 改为按每个 `show_total`/`show_figures`/`show_tags`/`show_feed` 独立控制对应组件显隐
  - 全部关闭时展示「该用户未公开任何数据」
- **前端** `SharePoster.vue`：
  - 移除 `showStats`（已无意义，海报始终展示统计数字）
  - `showAmount` 改为仅由 `posterLevel === 'full'` 控制，不再依赖 `show_asset`
  - 海报渲染逻辑纯由「海报展示数据」（poster_level）驱动

### 结果
- 两套配置职责清晰独立，互不干扰
- 主页 Web 页面由「数据展示」开关独立控制，poster_level 不再影响
- 海报 PNG 由「海报展示数据」独立控制，show_asset 等数据展示开关不再影响

### 7. 修复分享页复用 ActivityFeed 组件时触发登录重定向

**解决方案：** 分享页 `ShareProfile.vue` 复用 `ActivityFeed` 组件渲染动态流。但 `ActivityFeed` 组件在 `setup()` 中无条件调用 `feed.loadActivities('all')` → `GET /collector/timeline`，该后端接口依赖 `get_current_user`（需要 JWT 认证）。分享页访问者没有登录态，导致 401 跳转登录页。

**实现逻辑：**
- **前端** `ActivityFeed.vue` `setup()`：

  - 若为仪表盘模式（无外部数据）：保持原有逻辑，通过 API 加载
- 其他复用组件（`CollectorOverview`、`CollectionCabinets`、`TagCloud`）均为纯 props 渲染组件，无 API 调用，无此问题

### 结果
- 分享页不再因 ActivityFeed 组件触发未认证的 API 请求，无需登录即可正常查看
- 动态流数据直接使用 `/share/activities/{user_id}` 接口返回的数据展示

### 15. 隐私设置「主页资产金额」关闭时隐藏分享页价格敏感数据

**解决方案：** 隐私设置「数据展示」模块中的「主页资产金额」（`show_asset`）控制分享页是否展示成本价、市值、盈亏等敏感财务数据。当关闭时，动态流事件标题中的所有价格数据应被掩码替换，避免泄露敏感信息。

**实现逻辑：**
- **前端** `useActivityFeed.js`：`formatEventTitle` 函数新增 `showAsset` 参数（默认 `true`），当 `showAsset = false` 时，在格式化前先对标题执行价格掩码：将 `¥数字`、`$数字` 等替换为 `¥***`，将 `盈利 ¥数字` / `亏损 ¥数字` 替换为 `盈利 ¥***` / `亏损 ¥***`，然后直接返回掩码后的纯文本，跳过后续的高亮/颜色格式化
- **前端** `ActivityFeed.vue`：
  - 新增 `showAsset` 计算属性，从 `collectorData?.show_asset` 读取（默认 `true`）
