# 2026-07-10 更新日志

### 1. 修复登录偶发 500 Internal Server Error

**解决方案：** 排查后端日志确认报错为 `pymysql.err.OperationalError: (2013, 'Lost connection to MySQL server during query')`，并非代码 bug，而是 MySQL 服务端在 `wait_timeout` 后主动断开了空闲连接，pymysql 未自动重试所致。属于"部署后第一次请求"或"用户长时间未操作后登录"这类偶发场景。

**实现逻辑：**

- **后端 `database.py`**：SQLAlchemy `create_engine` 增加 `pool_pre_ping=True`（每次取连接前先 `SELECT 1` 健康检查，自动剔除失效连接）和 `pool_recycle=1800`（30 分钟主动回收，避开 MySQL `wait_timeout`），同时设置 `pool_size=10`、`max_overflow=20`、`pool_timeout=30`，使连接池更稳健。
- **后端 `auth.py`**：登录/注册接口增加 `OperationalError` / `DBAPIError` 异常捕获，DB 抖动时返回 503 + "服务暂不可用，请稍后重试"，避免直接抛 500 给用户。
