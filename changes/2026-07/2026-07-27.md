# 2026-07-27 更新日志

---

## 新增功能

### 1. 手办规格模块新增「来源链接」字段

**解决方案：** 在手办库「添加/编辑手办」表单的「规格」标签页中，「备注」字段之后新增「来源链接」输入框，记录手办信息来源 URL（HPOI / Amiami / MFC 等）。数据持久化到 `figures` 表的 `source_url` 字段。

**实现逻辑：**

- **后端** `schemas/figure.py`：
  - `FigureBase` 新增 `source_url: str | None = None` 字段，供创建手办时传入
  - `FigureUpdate` 新增 `source_url: str | None = None` 字段，供编辑手办时传入
  - `FigureListItem` 新增 `source_url: str | None = None` 字段，供列表查询返回

- **后端** `figure_query_service.py`：
  - `get_figures_list` 和 `get_figures_with_stock` 两个查询入口均在构建 `FigureListItem` 时新增 `source_url=figure.source_url` 参数

- **前端** `FormSpecsTab.vue`：Template 中「备注」字段之后新增「来源链接」`el-input`，绑定 `localFigure.source_url`；新增 `sourceUrlError` prop 和 `validate-source-url-input` emit

- **前端** `FigureForm.vue`：props 和 emits 新增 `sourceUrlError` / `validate-source-url-input`，template 中透传绑定

- **前端** `useFigureManagement.js`：`defaultFigure` 新增 `source_url: ''` 默认值；新增 `sourceUrlError` ref 和 `validateSourceUrlOnInput` 方法

- **前端** `Figures.vue`：表单绑定新增 `source-url-error` prop 和 `@validate-source-url-input` 事件，setup 中解构新增的 ref 和方法

### 2. 「来源链接」从规格信息移至基本信息

**解决方案：** 将手办详情页中的「来源链接」展示从「规格信息」卡片移至「基本信息」卡片，「备注」字段之后显示，与添加/编辑表单中的位置保持一致。

**实现逻辑：**

- **前端** `FigureBasicInfo.vue`：Template 中「备注」info-item 之后新增「来源链接」info-item，链接可点击（新窗口打开）；`hasContent` 新增 `f.source_url` 判断；新增 `.source-link` CSS 样式

- **前端** `FigureSpecInfo.vue`：移除来源链接 spec-item 和相关 CSS；`hasContent` 恢复为仅判断 `scale / material / size`

### 3. 修复来源链接换行与 hover 下划线缺陷

**解决方案：** 手办详情页基本信息中的「来源链接」数据与标签不应换行，且链接 hover 时不应出现下划线。

**实现逻辑：**

- **前端** `FigureBasicInfo.vue`：来源链接 info-item 的 class 从 `info-item-full`（flex-direction: column，换行）改为 `info-item`（flex-direction: row，同行）；移除 `.source-link:hover` 中的 `text-decoration: underline`；新增 `.link-value` 样式（max-width: 380px + overflow: hidden）

### 4. 修复尾款管理已完成排序

**解决方案：** 尾款管理切换到「已完成」状态时，订单按出荷日期降序排序（最新出荷的排在前面），而非升序。

**实现逻辑：**

- **前端** `useOrderManagement.js`：在 `filteredOrders` 排序函数中新增 `currentStatus.value === '已完成'` 分支，按 `dueB - dueA`（出荷日期降序）排序

### 5. 修复订单卡片订单编号超长无换行

**解决方案：** 订单卡片中的「订单编号」文本数据可能较长（如 UUID 或长数字串），缺少 `word-break` 样式会导致内容溢出卡片边界。

**实现逻辑：**

- **前端** `OrderItem.vue`：在 `.order-item p` 样式中新增 `word-break: break-all`，使长文本可在字符间自动换行
