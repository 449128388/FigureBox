## 缺陷修复 → 3. 上一版（#1/#2）"拖拽区 flex 居中"未真正生效，文字仍处于下方靠左偏右位置（非上下左右严格居中）

**解决方案：** 上一版（#1）虽然把 `.license-dropzone` 改成了 `display: flex; flex-direction: column; align-items: center; justify-content: center; min-height: 140px`，但**实际渲染时文字仍处于容器下半部分、未严格垂直居中**。根因分析：① 拖拽区内 SVG 元素使用了内联 `stroke="var(--text-tertiary)"` + `style="margin-bottom:10px;display:block;margin-left:auto;margin-right:auto"`，内联样式与父级 flex 规则叠加产生 baseline 偏差（行内 SVG 在 flex 容器中仍占据 4px 左右 baseline 空间，干扰 `justify-content: center` 的对齐计算）；② 同时 `.license-dropzone > svg` 选择器又额外加了 `margin: 0 auto 10px`，与 SVG 内联 margin 冲突；③ `min-height: 140px` 在 SVG + 2 段文字 + margin 总和约 110px 的情况下，容器实际高度被 padding 撑到 ~188px，但 flex 居中算法在「SVG 不可见」+ 「inline 元素 baseline」+ 「text-align: center 残留」三重干扰下计算出错误中心点，导致文字偏下。修法：① 弃用 flex 居中、改用 **CSS Grid + place-items: center** 居中方案（grid 居中算法对子元素 baseline / 隐式行高不敏感，是目前最严格居中的方案）；② 在拖拽区内引入一个 `.license-dropzone-inner` 包装层（三块内容：图标 + 主文字 + 副文字），外层用 grid 单格居中、内层用 flex 纵向排版并 `text-align: center` 水平居中，两层解耦；③ SVG 改为类名 `.license-dropzone-icon` + 固定 `width: 44px; height: 44px; margin: 0 auto 12px`，去掉所有内联 `style` + `var(--text-tertiary)` 改用实色 `#c0c4cc`（解决 CSS 变量作用域问题，让图标在 hover 浅蓝背景下可见）；④ 两段文字拆为 `.license-dropzone-text` / `.license-dropzone-hint` 两个类，固定 line-height: 1.5 + text-align: center，让浏览器对每段文字的高度可精确计算，grid 居中就能找到真正的几何中心。**视觉上**：原方案文字悬浮在容器下半部分（约 60%-65% 位置）→ 新方案文字严格位于容器几何中心（50% 位置），hover 时高度恒定无抖动。

**实现逻辑：**

- **拖拽区布局策略升级（flex → grid）**：
  - `.license-dropzone` 改用 `display: grid; place-items: center; min-height: 160px` 替代原 `display: flex; ...; min-height: 140px`
  - `place-items: center` 等价于 `align-items: center; justify-items: center` 同时设置水平和垂直居中，比 flex 更严格（grid 单格对齐无视子元素 baseline / 隐式行高干扰）
  - `min-height: 140px → 160px`：原 140px 加上 padding 48px 后内容区仅 92px，3 块子元素总和 ~110px 略溢出导致 flex 计算异常；160px 留足缓冲，内容 + 上下空白对称
- **新增 inner 包装层（两层布局解耦）**：
  - `.license-dropzone-inner` 用 `display: flex; flex-direction: column; align-items: center; justify-content: center; text-align: center; width: 100%` —— 内部纵向排版 + 水平居中
  - 外层 grid 单格把 inner 当作"一个整体"居中，inner 内部再 flex 排版 3 块内容
  - 这种"外层严格几何居中 + 内层 flex 排版"的双层结构，是 CSS 中实现"容器内任意多块内容严格居中"的最稳健模式
- **SVG 重构（解决 CSS 变量 + 内联样式冲突）**：
  - 类名 `.license-dropzone-icon`：`width: 44px; height: 44px; display: block; margin: 0 auto 12px; flex-shrink: 0` —— 固定尺寸 + 块级元素（消除 baseline 干扰）+ 水平居中
  - `stroke` 改实色 `#c0c4cc` 替代 `var(--text-tertiary)`（CSS 变量在 dropzone 作用域内未定义会回退为空，导致图标不显示）
  - `stroke-linecap="round" stroke-linejoin="round"`：图标视觉更圆润
  - 去掉所有内联 `style`，统一走 CSS 类（避免与 grid / flex 规则叠加产生副作用）

  - `.license-dropzone-hint`：`font-size: 12px; color: #9499a0; margin-top: 6px; line-height: 1.5; text-align: center`
  - 显式 `line-height: 1.5` 让浏览器对每段文字的高度有精确计算（默认 line-height: normal 浏览器各自不同，会让 grid 居中算法算出不同中心点）
