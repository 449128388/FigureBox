# 2026-06-09 更新日志

## 1. 资产看板交易版块-快速操作-补款功能

### 需求描述
对资产看板-交易版块中的快速操作中的[补款]按钮进行新增需求，对已有预定订单（orders表中尾款状态为"未支付"）进行尾款支付。

### 解决方案
采用前后端分离架构，前端使用两步弹窗设计（选择订单 -> 确认支付），后端采用企业级服务层架构实现补款业务逻辑。

### 实现逻辑
**后端实现：**
- 创建 `PayBalanceService` 服务类，提供以下核心功能：
  - `get_pending_balance_orders`：获取待补款订单列表
    - 过滤条件：订单状态为"已支付"、尾款金额>0、尾款到期日<=今天+7天
    - 排序规则：逾期订单置顶，按到期日升序排列
  - `pay_balance`：支付尾款
    - 验证订单状态（必须为"已支付"）
    - 创建尾款交易记录（OrderTransaction）
    - 更新订单状态为"已完成"
    - 创建资产交易记录（入库）
    - 更新手办平均入手价格
  - `get_order_payment_detail`：获取订单支付详情
- 在 `trade_records_service/__init__.py` 中导出 `PayBalanceService`
- 在 `trade_records.py` 中添加三个API接口：
  - `GET /pending-balance-orders`：获取待补款订单列表
  - `GET /pending-balance-orders/{order_id}`：获取订单支付详情
  - `POST /pay-balance/{order_id}`：支付尾款

**前端实现：**
- 创建 `PayBalanceOrderListDialog.vue` 组件（Step 1：选择待补款订单）
  - 展示待补款订单列表
  - 显示手办图片、名称、尾款金额、到期日
  - 逾期订单标红置顶
  - 点击【去支付】进入确认页面
- 创建 `PayBalanceConfirmDrawer.vue` 组件（Step 2：支付确认）
  - 展示订单编号、尾款金额
  - 支持选择支付方式（支付宝、微信支付、银行卡等）
  - 支持选择支付时间
  - 支持部分支付（输入本次支付金额）
  - 确认支付后更新订单状态并入库
- 创建 `usePayBalance.js` composable
  - 管理补款相关的状态和行为
  - 提供两步补款流程控制
- 更新 `Dashboard.vue`
  - 导入补款组件和composable
  - 添加补款成功后的数据刷新逻辑
- 更新 `useQuickActions.js`
  - 添加补款相关的状态和方法

**与现有模块关联：**
- 尾款模块：订单从"待支付"列表移除，进入"已完成"
- 交易流水：生成买入聚合卡片（买入 -¥XXX，全款）
- 资产看板：持仓增加，总市值上升
- 持仓列表：新增或更新该手办卡片，显示"入手时间"

### 结果
- 支持查看待补款订单列表（未来7天内）
- 支持逾期订单标红置顶提醒
- 支持选择支付方式和时间
- 支持部分支付（分多期尾款）
- 支付成功后自动更新订单状态并入库
- 自动创建交易流水和资产记录
